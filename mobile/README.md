# حقّنا — تطبيق Android (Flutter)

تطبيق ميداني لجمعية حقّنا لتوثيق الناجين من المعتقلات السورية. نسخة طبق
الأصل عن تطبيق الويب من حيث البيانات، لكن بتصميم مناسب لأندرويد.

## المبدأ الأساسي

- **يعمل دون اتصال بالكامل.** كل البيانات تُخزَّن محلياً على الجهاز (SQLite).
- **لا حاجة لتسجيل الدخول عند بدء التشغيل.** يفتح مباشرة على قائمة الملفات،
  ويمكن للمتطوّع توثيق كل التفاصيل دون أي اتصال أو حساب.
- **تسجيل الدخول مطلوب فقط عند المزامنة** (رفع البيانات إلى السيرفر).

## ما الذي يمكن توثيقه؟ (مطابق لتطبيق الويب)

الهوية والبيانات الأساسية · الموافقة المستنيرة الطبقية · وقائع الاعتقال ·
فترات الاحتجاز (مع أنماط التعذيب ومراكز الاحتجاز الـ140+) · واقعة الإفراج ·
الشهود · الوثائق الداعمة · التقييمات الطبية (إسطنبول) · الأثر طويل الأمد ·
المقابلات · الملاحظات · المسح الاجتماعي الكامل (الأسرة، الأبناء، السكن،
التعليم، العمل والدخل، الصحة، تقييم الاحتياجات).

## البنية المعمارية

التطبيق مبني على **محرّك نماذج موجّه بالبيانات (metadata-driven)**: كل كيان
معرَّف كقائمة حقول (`EntitySpec`)، وتُرسم النماذج وتُخزَّن وتُزامَن آلياً من
هذا التعريف. هذا يجعل الكود مضغوطاً ومتّسقاً وسهل التوسعة.

```
lib/
├── main.dart                     ← نقطة الدخول (RTL، يفتح على القائمة مباشرة)
├── theme.dart                    ← ألوان وهوية حقّنا
├── data/
│   ├── field_spec.dart           ← أنواع الحقول + EntitySpec
│   ├── reference_data.dart       ← كل القوائم + مراكز الاحتجاز + أنماط التعذيب
│   └── entities.dart             ← تعريف كل الكيانات (مطابق لحقول Django)
├── db/
│   ├── app_database.dart         ← SQLite: جدول لكل كيان (حقول في عمود JSON)
│   ├── record.dart               ← نموذج سجل عام
│   └── record_repository.dart    ← CRUD عام لكل الكيانات
├── sync/
│   └── sync_service.dart         ← تسجيل الدخول + رفع الحزمة الكاملة
├── widgets/
│   ├── common.dart               ← عناصر مشتركة (عناوين، ألوان، عناوين السجلات)
│   └── record_form_screen.dart   ← محرّك النماذج العام
└── screens/
    ├── home_screen.dart          ← قائمة الناجين + بحث + زر المزامنة
    ├── survivor_detail_screen.dart ← لوحة الأقسام (توثيق + مسح اجتماعي)
    ├── record_list_screen.dart   ← إدارة الكيانات المتعددة
    └── sync_screen.dart          ← إعداد السيرفر + الدخول + الرفع
```

### كيف تعمل المزامنة؟

1. كل تعديل محلي يضع `needs_sync = 1` على السجل.
2. في شاشة المزامنة، يُدخل المتطوّع عنوان السيرفر وبيانات دخوله.
3. يُجمع لكل ناجٍ عليه تغييرات **حزمة كاملة** (الهوية + كل الأقسام) وتُرسل إلى
   `POST /api/v1/sync/push/`.
4. السيرفر يحفظ الملف وكل كياناته المرتبطة (الجوال هو المصدر لهذه الأقسام)،
   ويعيد معرّفات السيرفر، فتُعلَّم السجلات كمُزامَنة.

> الأقسام متعددة السجلات (الوقائع، الفترات، الشهود...) تُستبدل بالكامل عند كل
> مزامنة، لذا إعادة المزامنة آمنة ولا تُكرّر السجلات (idempotent).

## الإعداد والتشغيل

### 1. تثبيت Flutter
```bash
git clone https://github.com/flutter/flutter.git -b stable
export PATH="$PATH:`pwd`/flutter/bin"
flutter doctor
```

### 2. توليد ملفات المنصّات (مرة واحدة)
مجلد `lib/` و`pubspec.yaml` و`AndroidManifest.xml` جاهزة. لتوليد بقية ملفات
أندرويد (Gradle، MainActivity...) دون المساس بالكود:
```bash
cd mobile/
flutter create --platforms=android .
flutter pub get
```

### 3. التشغيل
```bash
flutter run                       # على جهاز/محاكي
flutter build apk --release       # لبناء APK للتوزيع
```

### 4. الاستخدام
- افتح التطبيق وابدأ التوثيق فوراً — **دون تسجيل دخول**.
- عند الرغبة بالرفع: اضغط أيقونة المزامنة ⟳، أدخل عنوان السيرفر
  (مثل `http://192.168.1.42:8000`) واسم المستخدم وكلمة المرور لحساب موثّق،
  ثم «تسجيل الدخول ورفع البيانات».

## الأمان

- رمز الدخول (Token) يُخزَّن في `flutter_secure_storage` (Android Keystore).
- يُسمح بـ HTTP غير المشفّر لشبكات LAN فقط (راجع `network_security_config.xml`).
- لا يُرسل أي شيء للسيرفر إلا عند طلب المزامنة صراحةً.

## نقاط الـAPI المُستخدَمة

| المسار | الطريقة | الوصف |
|--------|---------|-------|
| `/api/v1/auth/login/` | POST | تسجيل دخول → token |
| `/api/v1/sync/push/` | POST | رفع الحزمة الكاملة لكل ناجٍ |

## التوسعة

لإضافة حقل جديد: أضف `FieldSpec` في `entities.dart` بمفتاح يطابق اسم حقل
Django. يظهر تلقائياً في النموذج، ويُخزَّن، ويُزامَن — دون تعديل قاعدة البيانات
أو شيفرة المزامنة. لإضافة كيان جديد: عرّف `EntitySpec` وأضفه إلى
`kRelatedEntities` والمجموعة المناسبة.
